NapaSathi AI --- Smart Fabric Planning
Plan smarter. Visualize cutting layouts. Make better use of fabric.

NapaSathi AI is a web-based fabric-planning prototype designed to help
tailors, artisans, students, and small clothing businesses plan pattern
pieces on a fabric roll, estimate material usage, and understand
approximate material costs before cutting.
🌐 Live Demo
Try NapaSathi AI: https://devpost-11.vercel.app/

Source Code: https://github.com/kushwaha-78159/devpost-11
✨ Features
- Fabric roll configuration --- Set fabric roll width and length
  and choose measurement units.
- Pattern piece management --- Add, edit, and remove pattern
  pieces; change dimensions and quantities.
- Visual cutting layout --- Preview an approximate arrangement of
  pattern pieces on the fabric roll.
- Layout comparison --- Compare a baseline arrangement with an
  area-sorted arrangement.
- Fabric usage estimates --- View estimated used area, leftover
  fabric, and material utilization.
- Material cost estimation --- Enter a price per linear metre to
  estimate material cost.
- Save and export --- Save plans and export available planning
  information or CSV reports.
- Responsive interface --- Use the application on supported
  desktop and mobile browsers.
Important: NapaSathi AI is currently a planning prototype. Its
shelf-packing layout is approximate and does not guarantee a globally
optimal cutting arrangement or real-world fabric savings. Always check
fabric grain, pattern direction, seam allowances, shrinkage, and
cutting constraints before cutting.

🚀 Run Locally
Prerequisites
- Node.js (use a current version supported by your installed Next.js
  version)
- npm
Installation
1. Clone the repository:
   git clone https://github.com/kushwaha-78159/devpost-11.git
2. Open the project folder:
   cd devpost-11
3. Install dependencies:
   npm install
4. Start the development server:
   npm run dev
5. Open http://localhost:3000 in your browser.
Production build
To check and build the application:
npx tsc --noEmit
npm run build
To run the production build locally:
npm run start
🧭 How to Use
1. Open the live demo.
2. Configure the fabric roll dimensions and units.
3. Add or update pattern pieces and their quantities.
4. Review the cutting-layout preview.
5. Compare the available layout options and inspect the estimated usage
   and leftover material.
6. Enter a material price to review the cost estimate.
7. Save the plan or export the available report.
The exact results depend on the dimensions and quantities entered.
🛠️ Current Scope and Future Work
The current application focuses on browser-based fabric planning and
estimates. Planned improvements may include:
- More advanced fabric nesting and cutting-optimization algorithms
- Camera-assisted measurements with calibration and user verification
- Persistent cloud storage and account-based project history
- Reusable garment templates and richer costing options
- Testing with tailors and artisans to compare estimates with real
  cutting outcomes
- Additional language and accessibility improvements
These are future goals and should not be considered implemented features
unless they are added and tested in the application.
🌱 Why It Matters
Fabric is valuable, and planning before cutting can help people make
more informed decisions about material use. NapaSathi AI aims to make
basic digital fabric planning easier to explore for small tailoring
businesses and independent artisans.

Any real-world waste reduction or cost savings should be measured
through testing; the application does not claim guaranteed savings.
