# NapaSathi AI

Smart Measurement and Fabric Waste Reduction for Everyone.

NapaSathi AI aims to help small tailors and artisans measure materials and plan fabric cutting with less waste.

## Tech Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Planned: Python, FastAPI, OpenCV

## Status
Under active development. Measurement accuracy and waste-reduction results will be tested and reported honestly.

## Run Locally
```bash
npm install
npm run dev
```

Built for the Code for Humanity hackathon.
